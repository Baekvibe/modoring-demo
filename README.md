# 모두링 안부 (시연용 웹앱)

스마트링으로 어르신의 건강 신호를 모아, **어르신에게는 "오늘 괜찮은가"로, 보호자에게는 "평소와 달라졌는가"로** 보여 주는 케어 앱의 프로토타입입니다. 수원대 데이터과학부 5조 프로젝트.

> **시연용입니다.** 모든 데이터는 가짜(더미)이고, 서버·로그인·실제 알림 전송이 없습니다. 의료기기가 아니며 진단이 아니라 "평소와 달라졌음"만 알려 줍니다.

## 기능
- **어르신 화면**: 오늘 상태 신호등, 오늘 할 일(직접 추가·삭제), 내 기록(심박·HRV·산소·호흡·피부온도·스트레스·수면·활동 + 컨디션 점수), SOS, 내 위치 알리기
- **보호자 화면**: 가족 현황(위험도 순), 변화 추이(개인 평소 범위 대비 그래프), 알림 내역, 설정(알림 기준·할 일 편집·낙상 감지)
- **건강검진표 맞춤**: 숫자를 직접 넣으면 일반 참고 기준과 비교해 확인할 것·추천 할 일·낙상 위험도를 계산하고 앱에 적용
- **낙상 감지**: 떨어짐 → 충격 → 움직임 없음을 보는 알고리즘 + "괜찮으세요?" 확인 질문 + 가족 알림. 시연용 센서 기록 4종, 폰 센서(DeviceMotion)로도 동작
- 큰 글씨 3단계, 고대비 모드, iPhone(402pt) 기준 레이아웃

## 사용 방법·팀 작업 규칙
발표 시연 순서와 브랜치·PR로 작업하는 방법은 [사용방법.md](사용방법.md)를 보세요. `main`은 조장만 합칠 수 있습니다.

## 실행
정적 파일만 있어서 빌드가 필요 없습니다.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

로직 테스트(Node.js):

```bash
node tests/logic.test.js
```

## 구조
| 파일 | 역할 |
|---|---|
| `index.html` | 화면 틀 |
| `style.css` | 디자인 (Deep Rose 포인트, 이중 베젤 카드, 글래스 내비) |
| `logic.js` | 더미 데이터, 개인 기준선·신호등, 검진표 분석, 낙상 감지 (화면과 분리, Node에서 테스트 가능) |
| `app.js` | 화면과 동작 |
| `icons.js` | 내장 아이콘 (Solar) |

## 한계
- **검진표 분석은 실제 AI가 아닙니다.** 직접 넣은 숫자만 일반 기준과 비교해 계산하고, 올린 사진·PDF는 읽지 않고 예시 결과를 보여 줍니다. 실제 서비스에는 서버, 동의, 보관 정책, 법적 검토가 필요합니다(건강정보는 민감정보).
- **낙상 감지는 정확도가 검증되지 않았습니다.** 가짜 센서 기록으로만 동작을 확인했습니다. 링(손가락) 센서는 손목 기기보다 오탐·미탐이 많을 수 있습니다.
- 판정 기준은 일반 참고 기준이며, 실제로는 검진표에 인쇄된 판정이 우선입니다.
